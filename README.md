# Mappamondo

Le notizie del giorno in pillole e su una mappa interattiva. App web installabile: apri il sito da Safari, tocca Condividi › Aggiungi alla schermata Home.

- `index.html` — l'app
- `data/latest.json` — l'edizione del giorno, aggiornata in automatico alle 6:47, 13:13 e 19:43
- `data/archive/` — le edizioni dei giorni precedenti (ultimi 30 giorni) e `index.json` con l'elenco delle date
